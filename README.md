# H Market

Netlify uchun mini market sayt.

## Ishlaydigan sahifalar

- `/` — bosh sahifa
- `/admin` — yashirin admin panel
- `/product/:slug` — mahsulot sahifasi

## Admin

Standart parol: `admin123`

Netlify’da parolni o‘zgartirish uchun Environment variables ichida `ADMIN_PASSWORD` qo‘shing.

## Deploy

Netlify → Add new site → Import from GitHub → `malikamarket5001-wq/Hmarket` repo tanlang.

Build command bo‘sh qoladi. Publish directory: `.`
